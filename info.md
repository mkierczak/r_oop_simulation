
### Info
**Dr. Contagio** is a Shiny app for simulating disease spreading. It has been first developed as a 
standalone R code that is an illustration of using Object Oriented Programming (OOP), in particular R6 classes in R for modeling. It has been developed first time as teaching material for livecode demonstration during [RaukR2024](https://nbisweden.github.io/raukr-2024/) Summer School and actively developed and turned into this Shiny app at [RaukR 2025](https://nbisweden.github.io/raukr-2025/) OOP and Shiny session.
